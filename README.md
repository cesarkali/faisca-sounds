# Faísca sounds

Sound packs for **Faísca**, the little light that lives on the pill of
[Mac Island & Dock](https://windhawk.net/mods/mac-island-dock), a
[Windhawk](https://windhawk.net) mod.

The mod downloads a pack only when you pick it in Faísca's settings, once,
from [jsDelivr](https://www.jsdelivr.com)'s CDN. It asks only for these
files: nothing about you is sent.

## Packs

| Pack | Folder | Files |
| :--- | :--- | :--- |
| Glass | [`glass/`](glass) | 25 sounds, mono 16-bit WAV at 22050 Hz, about 1.3 MB in all |

Each pack has one `<event>.wav` for each of Faísca's events: `notify`, `eat`,
`drink`, `love`, `tap`, `angry`, `frustrated`, `proud`, `startled`, `yawn`,
`sneeze`, `file-copy`, `file-move`, `download`, `screenshot`, `charger`,
`usb`, `wifi-down`, `wifi-up`, `song`, `pomodoro-done`, `reminder`,
`game-catch`, `game-miss`, `game-record`. An event without its file keeps the
island's own sound.

The Glass sounds are synthesized from the island's own recipes as glassy
bells. Nothing here is a recording.
